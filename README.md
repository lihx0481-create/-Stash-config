⚠️ 面板真实性说明

本项目尽量只显示实际请求、实际检测以及实际存在的数据。

DNS 查询成功 ≠ DNS 无泄漏
WebRTC 服务可访问 ≠ WebRTC 无泄漏

因此 DNS 和 WebRTC 检测项目均保留「手动检测」方式，用于进行真正的泄漏检测。

无法可靠检测的项目不会伪造结果。

本项目用于 Stash 网络状态、连通性及泄漏检测辅助。

检测结果受当前网络、节点、DNS 和目标服务器影响，仅代表检测时的实际状态。
