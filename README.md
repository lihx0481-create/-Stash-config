## 🧩 Zika 自维护原则

- 自己维护，自己测试
- 不伪造检测结果，不隐藏未知问题
- 规则尽量针对实际请求编写
- 保持配置结构清晰

## ⚠️ 面板真实性说明

本项目只显示实际请求、实际检测以及实际存在的数据。

- DNS 查询成功 ≠ DNS 无泄漏
- WebRTC 服务可访问 ≠ WebRTC 无泄漏

因此 DNS 和 WebRTC 检测均保留「手动检测」方式。无法可靠检测的项目不会伪造结果。

检测结果受当前网络、节点、DNS 和目标服务器影响，仅代表检测时的实际状态。
